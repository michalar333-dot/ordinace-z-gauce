# Ordinace z gauče

Malá fyzio hra pro nemocnou fyzioterapeutku. Dojdi k lehátku, vyslechni pacienta a vyber odpověď. Odborné případy (BPPV, LCA, Achillovka, kauda equina, HSSP…) se střídají s vtipnými. Na každého pacienta padne jedno kafe, takže občas musíš ke kávovaru, a s některými pacienty můžeš pokračovat ve cvičebně.

Hraje se v prohlížeči, stačí otevřít `index.html`.
